# Wireshark Traffic Analysis

## Overview
This project demonstrates packet capture and protocol analysis using Wireshark.

## Steps
1. **Connectivity Test** – Ping wikipedia.org
2. **Packet Capture** – Capturing traffic on eth0
3. **Filters Applied**
   - ICMP (ping)
   - DNS queries
   - HTTP requests
   - TCP/TLS streams
4. **Analysis**
   - Protocol breakdown
   - Handshake inspection
   - Application data

## Screenshots
- Ping output
- ICMP packets
- DNS resolution
- HTTP GET request
- TLS handshake

## Conclusion
Wireshark provides deep visibility into network communication, useful for diagnostics and cybersecurity learning.
